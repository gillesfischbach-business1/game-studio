# Audio credits

All files in this folder were cut, looped, converted to mono and re-encoded by
`tools/audio/mkaudio.py` and `tools/audio/mkaudio2.py`. Each derived file keeps its source license. Derivatives
of CC BY-SA sources are shared under the same license.
